Репутация проверяется через OpenPhish.eu; при наличии PHISHTANK_API_KEY дополнительно используется PhishTank. При недоступности источников обычная ссылка не блокируется только из-за ошибки сети.
Используется для действия «Ограничить участника». Для совместимости с Telegram минимум — 30 секунд.
