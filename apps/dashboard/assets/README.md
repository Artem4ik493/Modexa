# Modexa Dashboard assets

Положи сюда два файла:

- `logo.png` — основной логотип Modexa. Используется в окне входа и в шапке Dashboard.
- `favicon.ico` — иконка Modexa для вкладки браузера.

Ожидаемые пути:

`apps/dashboard/assets/logo.png`
`apps/dashboard/assets/favicon.ico`

Рекомендуемый `logo.png`: квадратный PNG с прозрачным фоном, например 512×512 или 1024×1024.

После добавления файлов закоммить их в репозиторий. Dashboard отдаёт их по:

- `/assets/logo.png`
- `/assets/favicon.ico`
